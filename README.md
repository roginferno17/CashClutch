<summary><h3>📱 Tutorial 1: How to Download & Install CashClutch APK</h3></summary>

1. **Download the APK**

2. **Authorize Installation (If Prompted)**
   - When Chrome or your file manager prompts with *"File might be harmful"* or *"For your security, your phone is not allowed to install unknown apps from this source"*:
     - Tap **Settings** on the prompt.
     - Toggle ON **Allow from this source**.
     - Return to the installer and tap **Install**.

3. **Complete Installation**
   - Wait 5–10 seconds for the Android package manager to complete verification.
   - Tap **Open** to launch CashClutch immediately!

<details>
<summary><h3>⚙️ Tutorial 2: Initial Setup & First Order Hunting</h3></summary>
<br />

1. **Launch CashClutch**
   - Open the app from your home screen or app drawer.

2. **One-Time Session Sign-In**
   - On the integrated cashier viewer, log into your trading account. 
   - Thanks to CashClutch's persistent session retention, you only need to sign in once. Your session remains alive across subsequent app launches without relogins.

3. **Configure Amount Ranges**
   - On the main dashboard, set your desired Minimum Amount (₹) and Maximum Amount (₹).
   - Set the check count or leave default.

4. **Start Automation**
   - Tap **Start / Run Bot**.
   - CashClutch will monitor active orders and automatically snatch matching slots with sub-second execution!

</details>

<br />

<details>
<summary><h3>🔋 Tutorial 3: Optimal Battery & Background Settings</h3></summary>
<br />

To ensure CashClutch can run continuously in the background without Android OS Doze mode pausing your search:

1. Open your device **Settings** $\to$ **Apps** $\to$ **CashClutch**.
2. Tap **Battery** (or *App battery usage*).
3. Select **Unrestricted** (or toggle OFF *Put app to sleep / Pause app activity if unused*).
4. Tap **Notifications** and ensure notifications and sound alerts are enabled.

</details>

## 💬 Frequently Asked Questions (FAQ)

<details open>
<summary><b>Q1: Why does Android show "File might be harmful" when downloading?</b></summary>
<br />

This is the standard security notice shown by Android whenever downloading any `.apk` file directly through a browser instead of the Google Play Store. CashClutch is completely safe, digitally signed with official release keys (Android Signature Scheme v2 + v3), and contains zero trackers or third-party ad libraries. Tap **Download anyway** to proceed.

</details>

<br />

<details>
<summary><b>Q2: Does CashClutch run with the screen locked or app minimized?</b></summary>
<br />

**Yes.** CashClutch includes a dedicated foreground background service with CPU wake locks designed specifically to keep the order hunting engine active while your screen is off or while using other applications.

</details>

<br />

<details>
<summary><b>Q3: How do I know when an order is secured?</b></summary>
<br />

When an order is successfully snatched, CashClutch triggers:
- A high-gain audio chime to wake you up immediately.
- Continuous tactile vibration pulses.
- A heads-up system notification with a direct **Pay Now** action button that takes you straight to the payment screen with QR code and UPI deep links.

</details>

<br />

<details>
<summary><b>Q4: How do I silence or mute the alarm?</b></summary>
<br />

You can mute the alert at any time:
- Tap the **Mute bell** icon on the top banner or dashboard.
- Tap the **Pay Now** button on the alert card.
- Tapping mute gives instant visual color feedback and silences the audio.

</details>

<br />

<details>
<summary><b>Q5: How do app updates work?</b></summary>
<br />

CashClutch includes automatic version checking. When a newer release is published, the app displays a direct update notice with a 1-tap download button. You never have to manually search for updates.

</details>

<br />

<details>
<summary><b>Q6: What devices and Android versions are supported?</b></summary>
<br />

CashClutch is compatible with all modern Android smartphones running **Android 7.0 (Nougat, API 24) through Android 15+**, supporting both 64-bit (`arm64-v8a`) and 32-bit (`armeabi-v7a`) chipsets.

</details>
